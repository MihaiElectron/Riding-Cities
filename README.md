# Riding Cities

## Description

Riding Cities est un projet d'intégration HTML réalisé dans le cadre de la formation Développeur Intégrateur Web d'OpenClassrooms.

L'objectif était de mettre à jour le site d'une association de skate en intégrant de nouveaux contenus à partir d'une maquette fournie. Le projet consistait principalement à créer une nouvelle section dédiée aux membres fondateurs de l'association et à restructurer la zone de téléchargement des plannings de cours.

## Objectifs

* Intégrer une nouvelle section à partir d'une maquette Figma.
* Structurer une page web en HTML sémantique.
* Réutiliser et adapter du code existant.
* Utiliser des classes CSS déjà présentes sans modifier la feuille de style.
* Assurer la cohérence visuelle avec la maquette fournie.

## Technologies utilisées

* HTML5
* CSS3 (classes existantes)
* Visual Studio Code
* Figma
* GitHub Copilot

## Compétences développées

* Structuration sémantique d'une page web
* Intégration de contenu textuel et visuel
* Utilisation d'images et gestion des attributs d'accessibilité
* Création de liens de téléchargement
* Analyse et reproduction d'une maquette
